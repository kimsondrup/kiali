=== querypb

Kiali's trimmed copy of Grafana Tempo's query IDL, generated with `protoc-gen-go`.

It carries the streaming search RPC Kiali calls, its request, and the search answer
both the gRPC and the HTTP transport return. Tempo's write path, its block and tag
RPCs, and the trace detail are left out. Span attributes come from the published
`go.opentelemetry.io/proto/otlp` module rather than the copy of the OTLP model Tempo
carries under its own package, so no OTLP type is generated here.

==== Version

Trimmed from Tempo *v2.3.0*, which is the release the generated code this replaced was
taken from. The numbers later releases added are `reserved` rather than declared, so a
field Kiali does not read cannot silently become one it does. Moving to a later IDL is
its own change, not a side effect of regenerating this one.

`hack/gen-tempo-protos.sh` fetches that release's IDL and refuses to generate unless
every field declared here exists upstream at the same number, so the trim is checked
rather than asserted. A number that drifts is a wire incompatibility nothing else would
notice: the generated code's own tests pin what was recorded here, not what upstream
says.

==== Licence

Upstream source: https://github.com/grafana/tempo/blob/v2.3.0/pkg/tempopb/tempo.proto[pkg/tempopb/tempo.proto].

Tempo as a whole is AGPL-3.0, which Kiali cannot take. Its
link:https://github.com/grafana/tempo/blob/v2.3.0/LICENSING.md[LICENSING.md] carves out
`pkg/tempopb` and `operations/` as Apache-2.0, and that carve-out is the only thing that
makes this copy usable here. `LICENSE_APACHE2` is that licence.

`hack/gen-tempo-protos.sh` asserts the carve-out still names `pkg/tempopb` before it
generates anything, so an upstream relicence stops the script rather than being found
by someone reading this file.

==== Regenerating

`hack/gen-tempo-protos.sh` regenerates `tempo.pb.go` and `tempo_grpc.pb.go`. It fetches
protoc, the plugins and the OpenTelemetry protos at pinned versions, so the output is
reproducible; set `PROTOC` to use a protoc already installed. Run it after editing
`tempo.proto` and commit what it changes.
